# ArcheOS 开发计划

## M0 基础规范

目标：建立信息生命周期和目录规则。

交付：
- Agent.md
- 目录结构
- 文档规范

## M1 销售录音闭环

目标：跑通第一条业务链。

流程：
录音 → 转写 → 纪要 → 原子信息 → 客户/项目更新 → 建议

## M2 核心对象能力

支持：
- Person
- Company
- Project
- Event

## M3 决策闭环

支持：
- Goal
- Decision
- Action
- Feedback

## M4 多格式输入

扩展：
- PDF
- 图片
- 视频
- PPT

原则：先闭环，再扩展。
